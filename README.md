# ✈️ VoyageAI — AI Travel Companion

VoyageAI is an AI-powered travel planning app built with **Flutter and Dart** that creates personalized travel itineraries for destinations in Pakistan.

Users enter their **destination, budget, number of travellers, interests, and travel style**, and Gemini AI generates a detailed day-by-day itinerary.

## ✨ Features

* 🤖 AI-generated personalized itineraries
* 🔄 Regenerate the complete trip or a specific day
* 🌤️ Destination weather information
* 📍 Location and destination information
* 🖼️ Dynamic destination images
* 💰 Budget breakdown and estimated costs
* 💡 Travel, transport, safety, and insider tips
* 🔥 Firebase integration

## 🛠️ Tech Stack

* **Flutter & Dart**
* **Gemini AI**
* **Firebase**
* **REST APIs**
* **Weather API**
* **Location/Geocoding API**
* **Unsplash API**
